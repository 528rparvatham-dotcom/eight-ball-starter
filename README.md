# Theme Name: Magic 8 Ball
Soccer Psychic
## Project Overview
Soccer Matchday prediction website. Type in manager's name and question, and let the soccer psychic decide the outcome of the game.
## Design Decisions
Wanted a soccer ball instead of a magic 8 ball. Made the cards green, color of soccer pitch, with the use of Google Gemini.
